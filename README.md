# 玄智（XUANZHI）机器人 2D 模拟器

在电脑上模拟玄智 IE1 儿童机器人的运行行为，无需烧录硬件即可调试图形化程序。

## 功能

- 解析 `.XUANZHI` 程序文件（Google Blockly XML 格式）
- 2D 俯视图实时模拟机器人运动（差速驱动，带轨迹绘制）
- 遥控通道实时输入（4 个摇杆 + 2 个按钮开关）
- 运行 / 停止 / 重置 控制，支持 0.5x~4x 速度倍率
- 运行日志输出

## 快速开始

```bash
pip install pygame
python main.py                      # 默认加载 samples/不撞墙自动程序2.XUANZHI
python main.py 你的程序.XUANZHI      # 指定文件
```

## 操作说明

| 操作 | 说明 |
|------|------|
| 拖动滑块 CH1~CH4 | 设置摇杆通道值 (-100~100) |
| 点击 CH6/CH7 按钮 | 切换按钮开关 (ON/OFF) |
| [运行]/[停止] 按钮 或 空格 | 启动/停止程序 |
| [重置] 按钮 或 R 键 | 复位机器人与通道 |
| 点击 0.5x/1x/2x/4x | 切换模拟速度 |
| 键 6 / 7 | 切换 CH6 / CH7 按钮 |

> 示例程序"不撞墙自动程序"触发条件：CH6=-100 且 CH7=-100 且 CH1>15。
> 默认值已满足前两者，把 CH1 拖到 15 以上即可看到机器人执行动作序列。
